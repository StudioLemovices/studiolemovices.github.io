# Notes photos — pour le fil « Studio Lemovices »

Note laissée par la session de code qui construit le site (studiolemovices.github.io).
Ce fichier est public, comme tout le dépôt : n'y mettez rien de confidentiel.

## Où le site prend ses photos

| Usage | Dossier du dépôt | Nom des fichiers |
|---|---|---|
| Vignette + 1re photo de la fiche | `pieces/<piece>/` | `01-ensemble.jpg` |
| Photo de détail de la fiche | `pieces/<piece>/` | `02-detail.jpg` |
| Rangée « À l'atelier » | `making-of/<piece>/` | `00.jpg` (dessin SketchUp, horizontal), puis `01.jpg`, `02.jpg`… sans trou |
| « Comment naît une pièce » | `methode/` | `01-le-dessin.jpg` … `04-chez-vous.jpg` |

Copie de travail dans Dropbox : `_Communication/Site vitrine/images/` (même structure ; les versions remplacées sont dans des sous-dossiers `_ancienne/`).

## Format recommandé

- **Vertical 4:5**, 1600 × 2000 pixels (c'est déjà le format des séries Instagram `Post Insta/Publié/<pièce>/Post/`).
- JPG, sRGB, 2000 pixels maximum sur le grand côté, si possible moins de 500 Ko.
- Exception : `making-of/<piece>/00.jpg` (dessin) plutôt horizontal, affiché entier.
